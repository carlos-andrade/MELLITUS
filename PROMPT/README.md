## 1. Finalidade

Esta pasta reúne prompts controlados utilizados para orientar o desenvolvimento do MELLITUS. Cada prompt deverá ter finalidade explícita, versão, estado, entradas e saídas esperadas, dependências, critérios de aceitação, riscos e evidências de validação.

## 2. Regras de utilização

- Aplicar a hierarquia e as regras do repositório [GOVERNANCA](https://github.com/carlos-andrade/GOVERNANCA).
- Preservar a cadeia documental `PROMPTS → CARTAS → LAYOUT ÚNICO → CÓDIGO`.
- Não tratar um prompt como autorização para implementar, publicar ou ultrapassar gates.
- Não inserir dados pessoais ou dados reais de saúde em prompts sem finalidade, base legal e controlos aprovados.
- Não produzir conteúdo clínico como validado sem fontes rastreáveis e revisão adequada.
- Não permitir diagnóstico, prescrição ou ajuste autónomo de medicação.
- Registar alterações, decisões, testes e evidências verificáveis.

## 3. Convenção para novos prompts

Cada prompt deverá, conforme aplicável, declarar:
1. ID único e nome do artefacto.
2. Objetivo, âmbito e exclusões.
3. Autoridade superior e documentos de entrada.
4. Papel esperado, tarefas e restrições.
5. Formato de saída e critérios de aceitação.
6. Requisitos de segurança, privacidade e revisão humana.
7. Testes, evidências, versão e histórico de alterações.

## 4. Estado inicial

A pasta foi criada com este índice inicial. Nenhum prompt operacional foi aprovado por este ato; novos artefactos permanecem em revisão até validação segundo a GOVERNANCA.
